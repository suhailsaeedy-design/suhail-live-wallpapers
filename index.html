QUICK GUIDE

How to use

Suhail Live Wallpapers works as an installable website. The website cannot silently change system wallpaper or write directly into Photos/Gallery, so saving always uses the device's approved browser/share controls.

01

Open a wallpaper

Tap a card to open the full-screen animated preview. Live scenes use real-time Canvas motion, so they remain smooth and lightweight.

02

Save to Photos / Gallery

Tap Save photo. On supported iPhone and Android browsers, the system share sheet opens so you can choose Save Image or a similar gallery action. Other browsers download the PNG file.

03

Save live motion

Tap Save live clip where Canvas recording is supported. If the browser cannot record the live canvas, use the phone's built-in screen recorder. Android launchers may accept video wallpaper; iPhone live-wallpaper behavior depends on the iOS version and media format.

04

Install & use offline

On iPhone, use Share → Add to Home Screen. The interface, About page and this guide are cached for offline use. Wallpaper browsing and search intentionally remain online-only so you always get the latest collection.

Privacy first. Favorites and theme preference stay in your browser. There is no account requirement and no tracking script in this version.

THE IDEA

One free web experience.

The project is built with standard web technology so it can run from GitHub Pages, install to a home screen, and stay easy to maintain without a database or paid backend.

THE EXPERIENCE

Motion that feels native.

Animated Canvas scenes, responsive controls, dark/light themes, full-screen previews, local favorites and device-approved export flows make the website feel close to a dedicated mobile app.

OFFLINE DESIGN

Useful even without internet.

The installed shell, creator page and usage guide remain available offline. Wallpaper content intentionally requires internet and shows a clear network message instead of failing or displaying stale catalog data.
