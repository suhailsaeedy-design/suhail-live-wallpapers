# Suhail Labs integration

Use the following project metadata when adding this project to the Suhail Labs website.

## Project title
Suhail Live Wallpapers

## Short description
A free installable web app with original procedural live wallpapers, instant previews, favorites, still-image export and supported live recording.

## Suggested tags
PWA, JavaScript, Creative Coding, Wallpapers, Mobile, Open Source

## Open button
Point the **Open** button to the deployed GitHub Pages URL for this repository.

## Repository button
Point the source/repository button to:
https://github.com/suhailsaeedy-design/suhail-live-wallpapers

## Important usage note
Web browsers cannot directly change a phone's system wallpaper. The project lets users preview and export wallpaper media; users then apply it through their device's Photos/Gallery or wallpaper settings. Live-motion support varies by device and operating-system version.
